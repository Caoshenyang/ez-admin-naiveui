## 1. 环境变量基础

### 1.1 什么是环境变量？

环境变量是在不同环境（开发、测试、生产）中可以变化的配置值。

```bash
# 开发环境
API_URL=http://localhost:3000/api

# 生产环境
API_URL=https://api.example.com
```

### 1.2 为什么需要环境变量？

```typescript
// ❌ 硬编码：不安全、不灵活
const API_URL = 'https://api.example.com'
const API_KEY = 'sk-1234567890' // 敏感信息泄露

// ✅ 环境变量：安全、灵活
const API_URL = import.meta.env.VITE_API_BASE_URL
const API_KEY = import.meta.env.VITE_API_KEY
```

## 2. Vite 环境变量

### 2.1 命名规范

Vite 使用特殊的环境变量命名约定：

- `VITE_` 前缀：暴露给客户端代码
- 无前缀：仅用于构建配置

```bash
# ✅ 客户端可访问
VITE_APP_TITLE=Ez-Admin
VITE_API_BASE_URL=https://api.example.com

# ❌ 客户端不可访问
DATABASE_URL=mysql://localhost:3306/db
SECRET_KEY=your-secret-key
```

### 2.2 内置环境变量

Vite 提供了一些内置变量：

```typescript
import.meta.env.MODE         // 当前模式：development | production
import.meta.env.BASE_URL     // 部署基础路径
import.meta.env.PROD         // 是否生产环境
import.meta.env.DEV          // 是否开发环境
import.meta.env.SSR          // 是否 SSR
```

## 3. 创建环境变量文件

### 3.1 环境文件列表

```
.env                # 所有环境通用（提交到 Git）
.env.local          # 本地覆盖（不提交）
.env.development    # 开发环境（提交到 Git）
.env.production     # 生产环境（提交到 Git）
```

### 3.2 创建配置文件

**.env** (通用配置):

```bash
# 应用标题
VITE_APP_TITLE=Ez-Admin-NaiveUI

# 应用版本
VITE_APP_VERSION=1.0.0
```

**.env.development** (开发环境):

```bash
# 模式
NODE_ENV=development

# API 配置
VITE_API_BASE_URL=http://localhost:3000/api
VITE_API_TIMEOUT=10000

# 功能开关
VITE_MOCK_ENABLED=true
VITE_DEBUG=true
```

**.env.production** (生产环境):

```bash
# 模式
NODE_ENV=production

# API 配置
VITE_API_BASE_URL=https://api.example.com
VITE_API_TIMEOUT=5000

# 功能开关
VITE_MOCK_ENABLED=false
VITE_DEBUG=false
```

**.env.local** (本地覆盖，不提交):

```bash
# 本地开发配置
VITE_API_BASE_URL=http://192.168.1.100:3000/api
```

### 3.3 Git 忽略规则

**.gitignore**:

```
# 环境变量
.env.local
.env.*.local
```

## 4. TypeScript 类型定义

### 4.1 扩展 ImportMetaEnv

**src/vite-env.d.ts**:

```typescript
/// <reference types="vite/client" />

interface ImportMetaEnv {
  // 应用配置
  readonly VITE_APP_TITLE: string
  readonly VITE_APP_VERSION: string

  // API 配置
  readonly VITE_API_BASE_URL: string
  readonly VITE_API_TIMEOUT: string

  // 功能开关
  readonly VITE_MOCK_ENABLED: string
  readonly VITE_DEBUG: string
}

interface ImportMeta {
  readonly env: ImportMetaEnv
}
```

### 4.2 创建环境变量工具

**src/utils/env.ts**:

```typescript
/**
 * 环境变量工具
 */
export const env = {
  // 应用配置
  get appTitle() {
    return import.meta.env.VITE_APP_TITLE
  },
  get appVersion() {
    return import.meta.env.VITE_APP_VERSION
  },

  // API 配置
  get apiBaseUrl() {
    return import.meta.env.VITE_API_BASE_URL
  },
  get apiTimeout() {
    return Number(import.meta.env.VITE_API_TIMEOUT)
  },

  // 功能开关
  get isMock() {
    return import.meta.env.VITE_MOCK_ENABLED === 'true'
  },
  get isDebug() {
    return import.meta.env.VITE_DEBUG === 'true'
  },

  // 环境判断
  get isDev() {
    return import.meta.env.DEV
  },
  get isProd() {
    return import.meta.env.PROD
  },
  get mode() {
    return import.meta.env.MODE
  },
}
```

## 5. 使用环境变量

### 5.1 在组件中使用

```vue
<script setup lang="ts">
import { env } from '@/utils/env'

console.log('应用标题:', env.appTitle)
console.log('API 地址:', env.apiBaseUrl)
console.log('当前环境:', env.mode)
</script>

<template>
  <div>
    <h1>{{ env.appTitle }}</h1>
    <p>版本: {{ env.appVersion }}</p>
    <p v-if="env.isDebug">调试模式已开启</p>
  </div>
</template>
```

### 5.2 在 API 请求中使用

**src/utils/request.ts**:

```typescript
import { env } from './env'

const request = axios.create({
  baseURL: env.apiBaseUrl,
  timeout: env.apiTimeout,
})

export default request
```

### 5.3 条件功能开发

```typescript
import { env } from '@/utils/env'

export const fetchData = async () => {
  if (env.isMock) {
    // 开发环境使用 Mock 数据
    return mockData
  }

  // 生产环境真实请求
  return await request.get('/data')
}
```

## 7. 最佳实践

### 7.1 敏感信息处理

```bash
# ❌ 错误：敏感信息放入 .env.development
VITE_API_SECRET_KEY=sk-1234567890

# ✅ 正确：使用 .env.local（不提交到 Git）
VITE_API_SECRET_KEY=sk-1234567890
```

### 7.2 类型安全访问

```typescript
// ❌ 不安全：字符串可能为空
const timeout = import.meta.env.VITE_API_TIMEOUT

// ✅ 安全：提供默认值和类型转换
const timeout = Number(import.meta.env.VITE_API_TIMEOUT) || 10000
```

### 7.3 环境变量验证

**src/utils/env-validate.ts**:

```typescript
/**
 * 环境变量验证
 */
export const validateEnv = () => {
  const required = ['VITE_API_BASE_URL', 'VITE_APP_TITLE']

  const missing = required.filter(key => !import.meta.env[key])

  if (missing.length > 0) {
    throw new Error(`缺少必需的环境变量: ${missing.join(', ')}`)
  }

  console.log('✅ 环境变量验证通过')
}

// 在 main.ts 中调用
import { validateEnv } from './utils/env-validate'

validateEnv()
```

## 8. 调试环境变量

### 8.2 使用环境变量显示徽章

```vue
<script setup lang="ts">
import { computed } from 'vue'
import { env } from '@/utils/env'

const envBadge = computed(() => {
  if (env.isDev) return '开发'
  if (env.mode === 'staging') return '预发布'
  return '生产'
})

const badgeColor = computed(() => {
  if (env.isDev) return 'blue'
  if (env.mode === 'staging') return 'orange'
  return 'green'
})
</script>

<template>
  <div class="env-badge" :style="{ background: badgeColor }">
    {{ envBadge }}
  </div>
</template>
```

## 9. 常见问题

### Q1: 修改环境变量后不生效？

**A**: 需要重启开发服务器：
```bash
# Ctrl+C 停止后重新运行
pnpm dev
```

### Q2: 环境变量在 build 后丢失？

**A**: 确保：
1. 变量名以 `VITE_` 开头
2. 变量在 `.env.production` 中定义
3. 正确构建：`pnpm build`

### Q3: 如何在服务器端使用环境变量？

**A**: 使用 `process.env`（Node.js）：
```javascript
// vite.config.ts
export default defineConfig({
  define: {
    'process.env.SERVER_URL': JSON.stringify(process.env.SERVER_URL)
  }
})
```
