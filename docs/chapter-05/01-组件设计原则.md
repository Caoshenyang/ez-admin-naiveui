## 1. 设计原则

### 1.1 单一职责

```vue
<!-- ✅ 好：组件职责单一 -->
<EzButton>按钮</EzButton>
<EzInput>输入框</EzInput>

<!-- ❌ 差：组件职责混乱
<EzButtonWithInput> -->
```

### 1.2 可复用性

```vue
<!-- ✅ 好：通过 props 自定义 -->
<EzButton type="primary" size="large">
  提交
</EzButton>

<!-- ❌ 差：硬编码 -->
<EzButton>提交</EzButton>
```

### 1.3 可组合性

```vue
<!-- ✅ 好：支持插槽组合 -->
<EzModal>
  <template #header>标题</template>
  <template #default>内容</template>
  <template #footer>底部</template>
</EzModal>
```

## 2. Props 设计

### 2.1 命名规范

```typescript
// ✅ 推荐：语义化
const props = defineProps({
  userName: String,
  isLoading: Boolean,
  onSubmit: Function,
})

// ❌ 避免：不清晰
const props = defineProps({
  name: String,     // 太通用
  flag: Boolean,    // 不明确
  callback: Function, // 不知用途
})
```

### 2.2 类型定义

```typescript
// ✅ 推荐：详细类型
interface Props {
  /** 用户名 */
  userName: string
  /** 是否加载中 */
  isLoading?: boolean
  /** 提交回调 */
  onSubmit: () => void
}

const props = withDefaults(defineProps<Props>(), {
  isLoading: false,
})

// ❌ 避免：any 类型
const props = defineProps({
  data: any,
})
```

### 2.3 Props 验证

```typescript
const props = defineProps({
  // 类型检查
  size: {
    type: String as PropType<'small' | 'medium' | 'large'>,
    default: 'medium',
    validator: (value: string) => {
      return ['small', 'medium', 'large'].includes(value)
    },
  },

  // 必填
  title: {
    type: String,
    required: true,
  },

  // 默认值工厂
  data: {
    type: Array as PropType<any[]>,
    default: () => [],
  },
})
```

## 3. 组件通信

### 3.1 Props Down, Events Up

```vue
<!-- 父组件 -->
<script setup lang="ts">
import EzChild from './EzChild.vue'

const handleSubmit = (data: any) => {
  console.log('收到子组件数据:', data)
}
</script>

<template>
  <EzChild :data="userData" @submit="handleSubmit" />
</template>

<!-- 子组件 -->
<script setup lang="ts">
const props = defineProps<{
  data: any
}>()

const emit = defineEmits<{
  submit: [data: any]
}>()

const handleSubmit = () => {
  emit('submit', props.data)
}
</script>
```

### 3.2 v-model

```vue
<!-- 父组件 -->
<script setup lang="ts">
import EzInput from './EzInput.vue'

const username = ref('')
</script>

<template>
  <EzInput v-model="username" />
</template>

<!-- 子组件 -->
<script setup lang="ts">
const props = defineProps<{
  modelValue: string
}>()

const emit = defineEmits<{
  'update:modelValue': [value: string]
}>()

const updateValue = (value: string) => {
  emit('update:modelValue', value)
}
</script>
```

## 4. 插槽设计

### 4.1 具名插槽

```vue
<!-- 组件 -->
<template>
  <div class="card">
    <slot name="header" />
    <slot />
    <slot name="footer" />
  </div>
</template>

<!-- 使用 -->
<EzCard>
  <template #header>
    <h1>标题</h1>
  </template>

  <p>内容</p>

  <template #footer>
    <button>按钮</button>
  </template>
</EzCard>
```

### 4.2 作用域插槽

```vue
<!-- 组件 -->
<script setup lang="ts">
const items = ref([{ id: 1, name: 'Item 1' }])
</script>

<template>
  <ul>
    <li v-for="item in items" :key="item.id">
      <slot name="item" :item="item" />
    </li>
  </ul>
</template>

<!-- 使用 -->
<EzList>
  <template #item="{ item }">
    <span>{{ item.name }}</span>
  </template>
</EzList>
```

## 5. 组件命名

### 5.1 命名规范

```
✅ 推荐：
- EzButton.vue      # 二次封装，Ez 前缀
- UserCard.vue      # 业务组件，多单词
- DataTable.vue     # 功能组件，多单词

❌ 避免：
- button.vue        # 单单词
- Button.vue        # 太通用
- ezbutton.vue      # 应使用 PascalCase
```

### 5.2 文件组织

```
components/
├── EzButton.vue          # 独立组件
├── EzForm.vue            # 独立组件
└── EzTable/              # 复杂组件，使用目录
    ├── EzTable.vue
    ├── EzTableColumn.vue
    └── types.ts
```
