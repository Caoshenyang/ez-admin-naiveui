## 1. 设计原则

### 1.1 单一职责

```vue
<!-- ✅ 好：组件职责单一 -->
<EzButton>按钮</EzButton>
<EzInput>输入框</EzInput>

<!-- ❌ 差：组件职责混乱
<EzButtonWithInput> -->
```

### 1.2 可复用性

```vue
<!-- ✅ 好：通过 props 自定义 -->
<EzButton type="primary" size="large">
  提交
</EzButton>

<!-- ❌ 差：硬编码 -->
<EzButton>提交</EzButton>
```

### 1.3 可组合性

```vue
<!-- ✅ 好：支持插槽组合 -->
<EzModal>
  <template #header>标题</template>
  <template #default>内容</template>
  <template #footer>底部</template>
</EzModal>
```

## 2. Props 设计

### 2.1 命名规范

```typescript
// ✅ 推荐：语义化
const props = defineProps({
  userName: String,
  isLoading: Boolean,
  onSubmit: Function,
})

// ❌ 避免：不清晰
const props = defineProps({
  name: String,     // 太通用
  flag: Boolean,    // 不明确
  callback: Function, // 不知用途
})
```

### 2.2 类型定义

```typescript
// ✅ 推荐：详细类型
interface Props {
  /** 用户名 */
  userName: string
  /** 是否加载中 */
  isLoading?: boolean
  /** 提交回调 */
  onSubmit: () => void
}

const props = withDefaults(defineProps<Props>(), {
  isLoading: false,
})

// ❌ 避免：any 类型
const props = defineProps({
  data: any,
})
```

### 2.3 Props 验证

```typescript
const props = defineProps({
  // 类型检查
  size: {
    type: String as PropType<'small' | 'medium' | 'large'>,
    default: 'medium',
    validator: (value: string) => {
      return ['small', 'medium', 'large'].includes(value)
    },
  },

  // 必填
  title: {
    type: String,
    required: true,
  },

  // 默认值工厂
  data: {
    type: Array as PropType<any[]>,
    default: () => [],
  },
})
```

## 3. 组件通信

### 3.1 Props Down, Events Up

```vue
<!-- 父组件 -->
<script setup lang="ts">
import EzChild from './EzChild.vue'

const handleSubmit = (data: any) => {
  console.log('收到子组件数据:', data)
}
</script>

<template>
  <EzChild :data="userData" @submit="handleSubmit" />
</template>

<!-- 子组件 -->
<script setup lang="ts">
const props = defineProps<{
  data: any
}>()

const emit = defineEmits<{
  submit: [data: any]
}>()

const handleSubmit = () => {
  emit('submit', props.data)
}
</script>
```

### 3.2 v-model

```vue
<!-- 父组件 -->
<script setup lang="ts">
import EzInput from './EzInput.vue'

const username = ref('')
</script>

<template>
  <EzInput v-model="username" />
</template>

<!-- 子组件 -->
<script setup lang="ts">
const props = defineProps<{
  modelValue: string
}>()

const emit = defineEmits<{
  'update:modelValue': [value: string]
}>()

const updateValue = (value: string) => {
  emit('update:modelValue', value)
}
</script>
```

## 4. 插槽设计

### 4.1 具名插槽

```vue
<!-- 组件 -->
<template>
  <div class="card">
    <slot name="header" />
    <slot />
    <slot name="footer" />
  </div>
</template>

<!-- 使用 -->
<EzCard>
  <template #header>
    <h1>标题</h1>
  </template>

  <p>内容</p>

  <template #footer>
    <button>按钮</button>
  </template>
</EzCard>
```

### 4.2 作用域插槽

```vue
<!-- 组件 -->
<script setup lang="ts">
const items = ref([{ id: 1, name: 'Item 1' }])
</script>

<template>
  <ul>
    <li v-for="item in items" :key="item.id">
      <slot name="item" :item="item" />
    </li>
  </ul>
</template>

<!-- 使用 -->
<EzList>
  <template #item="{ item }">
    <span>{{ item.name }}</span>
  </template>
</EzList>
```

## 5. 组件命名

### 5.1 命名规范

```
✅ 推荐：
- EzButton.vue      # 二次封装，Ez 前缀
- UserCard.vue      # 业务组件，多单词
- DataTable.vue     # 功能组件，多单词

❌ 避免：
- button.vue        # 单单词
```

## 7. NaiveUI + Tailwind CSS 组件开发规范

### 7.1 核心原则

**优先使用 NaiveUI 组件**，减少自定义布局：
- ✅ NaiveUI 组件负责交互逻辑、颜色主题
- ✅ Tailwind CSS 负责布局间距、响应式设计
- ❌ 避免过度使用 `dark:` 前缀（让 NaiveUI 主题系统处理）

### 7.2 组件使用优先级

```
NaiveUI 组件 > Tailwind 类名 > 自定义 CSS
```

**优先级表**:

| 场景 | 优先选择 | 示例 |
|------|---------|------|
| 布局间距 | `n-space` | `<n-space :size="8">` |
| 通用容器 | `n-el` | `<n-el tag="div">` |
| 按钮 | `n-button` | `<n-button type="primary">` |
| 卡片 | `n-card` | `<n-card title="标题">` |
| 弹窗 | `n-modal` | `<n-modal v-model:show="show">` |
| 布局容器 | Tailwind | `class="flex items-center space-x-4"` |
| 响应式 | Tailwind | `class="hidden md:block"` |

### 7.3 布局容器规范

#### 7.3.1 间距容器使用 `n-space`

```vue
<!-- ❌ 避免：自定义 flex 布局 -->
<div class="flex items-center space-x-4">
  <div>内容 1</div>
  <div>内容 2</div>
</div>

<!-- ✅ 推荐：使用 n-space -->
<n-space :size="16">
  <n-el tag="div">内容 1</n-el>
  <n-el tag="div">内容 2</n-el>
</n-space>
```

**n-space size 对应值**:
```typescript
:size="4"   // space-x-1 (4px)
:size="8"   // space-x-2 (8px)
:size="12"  // space-x-3 (12px)
:size="16"  // space-x-4 (16px)
```

#### 7.3.2 原生元素使用 `n-el` 包装

```vue
<!-- ❌ 避免：直接使用原生 HTML -->
<span class="text-sm font-medium">文本</span>
<input type="text" class="border rounded" />

<!-- ✅ 推荐：使用 n-el 继承主题 -->
<n-el tag="span" class="text-sm font-medium">文本</n-el>
<n-el tag="input" type="text" class="border rounded" />
```

**n-el 常用 tag 值**:
- `tag="div"` - 通用容器
- `tag="span"` - 文本容器
- `tag="input"` - 输入框
- `tag="button"` - 按钮

### 7.4 组件重构模式

#### 模式 1：flex 布局 → n-space

**Before**:
```vue
<div class="flex items-center space-x-4 flex-1 min-w-0">
  <n-button>按钮 1</n-button>
  <n-button>按钮 2</n-button>
</div>
```

**After**:
```vue
<n-space :size="16" class="flex-1 min-w-0">
  <n-button>按钮 1</n-button>
  <n-button>按钮 2</n-button>
</n-space>
```

#### 模式 2：原生元素 → n-el

**Before**:
```vue
<div class="flex items-center gap-2">
  <div class="w-8 h-8 bg-blue-500 rounded">
    <span class="text-white">E</span>
  </div>
  <span class="text-xl font-bold">Logo</span>
</div>
```

**After**:
```vue
<n-space :size="8">
  <n-el tag="div" class="w-8 h-8 bg-blue-500 rounded">
    <n-el tag="span" class="text-white">E</n-el>
  </n-el>
  <n-el tag="span" class="text-xl font-bold">Logo</n-el>
</n-space>
```

### 7.5 暗色模式处理规范

**原则**: 优先使用 NaiveUI 组件，避免手动写 `dark:` 类

```vue
<!-- ❌ 避免：手动处理暗色模式 -->
<div class="bg-white dark:bg-slate-900 border-slate-200 dark:border-slate-700">
  <span class="text-slate-900 dark:text-slate-100">内容</span>
</div>

<!-- ✅ 推荐：使用 NaiveUI 组件自动继承主题 -->
<n-card>
  <n-text>内容</n-text>
</n-card>
```

**何时使用 dark: 前缀**:
- ✅ 布局容器背景色（如 `bg-white dark:bg-dark-card`）
- ✅ 边框颜色（如 `border-slate-200 dark:border-dark-border`）
- ✅ 自定义容器（非 NaiveUI 组件）
- ❌ NaiveUI 组件内部（已自动处理）

### 7.6 导入规范

**所有使用的 NaiveUI 组件必须显式导入**（不依赖自动导入）：

```vue
<script setup lang="ts">
// ✅ 推荐：显式导入所有使用的组件
import {
  NButton,
  NCard,
  NInput,
  NSpace,
  NEl,
  NIcon,
  NDropdown
} from 'naive-ui'

// ❌ 避免：依赖自动导入（可能导致构建问题）
</script>
```

### 7.7 完整示例对比

#### Before（传统方式）:
```vue
<template>
  <div class="flex items-center space-x-4 p-4 bg-white dark:bg-slate-900 border border-slate-200 dark:border-slate-700 rounded-lg">
    <div class="flex items-center gap-2">
      <div class="w-8 h-8 bg-blue-500 rounded-lg flex items-center justify-center">
        <span class="text-white font-bold">E</span>
      </div>
      <span class="text-lg font-bold text-slate-900 dark:text-white">EzAdmin</span>
    </div>
    <button class="px-4 py-2 bg-blue-500 hover:bg-blue-600 text-white rounded transition-colors">
      提交
    </button>
  </div>
</template>
```

#### After（规范方式）:
```vue
<script setup lang="ts">
import { NSpace, NEl, NButton } from 'naive-ui'
</script>

<template>
  <n-el
    tag="div"
    class="flex items-center p-4 bg-white dark:bg-dark-card border border-slate-200 dark:border-dark-border rounded-lg"
  >
    <n-space :size="8">
      <n-el
        tag="div"
        class="w-8 h-8 bg-blue-500 rounded-lg flex items-center justify-center"
      >
        <n-el tag="span" class="text-white font-bold">E</n-el>
      </n-el>
      <n-el tag="span" class="text-lg font-bold text-slate-900 dark:text-white">
        EzAdmin
      </n-el>
    </n-space>

    <n-button type="primary">提交</n-button>
  </n-el>
</template>
```

### 7.8 迁移检查清单

重构现有组件时，按以下清单检查：

- [ ] 导入所有使用的 NaiveUI 组件
- [ ] 将 `flex + space-x-*` 布局替换为 `n-space`
- [ ] 将原生 HTML 元素（div、span、input）替换为 `n-el`
- [ ] 删除不必要的 `<style scoped>` 块
- [ ] 减少手动 `dark:` 前缀，优先使用 NaiveUI 组件
- [ ] 保留必要的 Tailwind 布局类（flex、grid、响应式等）
