```markdown
# EzButton 按钮组件

## 基础用法

\`\`\`vue
<EzButton type="primary">主要按钮</EzButton>
\`\`\`

## API

### Props

| 参数 | 说明 | 类型 | 默认值 |
|------|------|------|--------|
| type | 按钮类型 | `'primary' \| 'success' \| 'warning' \| 'danger'` | `'default'` |
| size | 按钮尺寸 | `'small' \| 'medium' \| 'large'` | `'medium'` |
| loading | 加载状态 | `boolean` | `false` |
| disabled | 是否禁用 | `boolean` | `false` |

### Events

| 事件名 | 说明 | 参数 |
|--------|------|------|
| click | 点击事件 | `event: MouseEvent` |

### Slots

| 插槽名 | 说明 |
|--------|------|
| default | 默认内容 |
| icon | 图标 |
```

## 2. 类型定义

### 2.1 组件 Props 类型

**src/components/EzButton/types.ts**:

```typescript
export interface EzButtonProps {
  /** 按钮类型 */
  type?: 'primary' | 'success' | 'warning' | 'danger' | 'default'
  /** 按钮尺寸 */
  size?: 'small' | 'medium' | 'large'
  /** 是否加载中 */
  loading?: boolean
  /** 是否禁用 */
  disabled?: boolean
  /** 图标 */
  icon?: string
}

export interface EzButtonEmits {
  /** 点击事件 */
  (e: 'click', event: MouseEvent): void
}
```

### 2.2 使用类型

```vue
<script setup lang="ts">
import type { EzButtonProps, EzButtonEmits } from './types'

const props = withDefaults(defineProps<EzButtonProps>(), {
  type: 'default',
  size: 'medium',
})

const emit = defineEmits<EzButtonEmits>()
</script>
```

## 3. 全局类型声明

### 3.1 组件注册

**src/types/components.d.ts**:

```typescript
declare module 'vue' {
  export interface GlobalComponents {
    EzButton: typeof import('./components/EzButton.vue')['default']
    EzForm: typeof import('./components/EzForm.vue')['default']
    EzTable: typeof import('./components/EzTable.vue')['default']
    EzModal: typeof import('./components/EzModal.vue')['default']
  }
}
```

### 3.2 自动导入配置

**vite.config.ts**:

```typescript
import Components from 'unplugin-vue-components/vite'
import { NaiveUiResolver } from 'unplugin-vue-components/resolvers'

Components({
  resolvers: [
    NaiveUiResolver(),
    (componentName) => {
      if (componentName.startsWith('Ez'))
        return { name: componentName, from: '@/components' }
    },
  ],
  dts: 'src/components.d.ts',
})
```
