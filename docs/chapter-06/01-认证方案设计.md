---

## 1. 认证流程

```
用户登录
    ↓
提交用户名密码
    ↓
后端验证
    ↓
返回 Token（Access Token + Refresh Token）
    ↓
存储 Token
    ↓
每次请求携带 Token
    ↓
Token 过期
    ↓
使用 Refresh Token 刷新
    ↓
刷新失败
    ↓
重新登录
```

---

## 2. Token 方案

### 2.1 Access Token

- 有效期短（15-30分钟）
- 用于 API 认证
- 存储在内存（Pinia）

### 2.2 Refresh Token

- 有效期长（7-30天）
- 用于刷新 Access Token
- 存储在 LocalStorage

---

## 3. 权限体系

### 3.1 RBAC 模型

```
用户 (User)
    ↓
角色 (Role)
    ↓
权限 (Permission)
```

### 3.2 权限类型

- **页面权限**: 控制菜单和路由访问
- **按钮权限**: 控制操作按钮显示
- **数据权限**: 控制数据范围
