## 2. 目录说明

### 2.1 api/ - API 接口管理

**作用**: 统一管理所有 API 请求

**示例**:
```typescript
// src/api/user.ts
import request from '@/utils/request'

export const userApi = {
  // 获取用户列表
  getList: (params: any) => request.get('/users', { params }),
  // 获取用户详情
  getDetail: (id: number) => request.get(`/users/${id}`),
  // 创建用户
  create: (data: any) => request.post('/users', data),
  // 更新用户
  update: (id: number, data: any) => request.put(`/users/${id}`, data),
  // 删除用户
  delete: (id: number) => request.delete(`/users/${id}`),
}
```

### 2.2 components/ - 公共组件

**作用**: 可复用的业务组件

**命名规范**:
- 二次封装组件使用 `Ez` 前缀：`EzButton.vue`, `EzTable.vue`
- 业务组件使用多单词：`UserCard.vue`, `ProductList.vue`

### 2.3 composables/ - 组合式函数

**作用**: 封装可复用的逻辑

**示例**:
```typescript
// src/composables/useAuth.ts
import { useUserStore } from '@/stores/user'

export function useAuth() {
  const userStore = useUserStore()

  const login = async (username: string, password: string) => {
    await userStore.login(username, password)
  }

  const logout = async () => {
    await userStore.logout()
  }

  return { login, logout }
}
```

**作用**: 页面布局容器

layouts/

### 2.5 stores/ - 状态管理

**作用**: 全局状态管理

**命名规范**: `useXxxStore`

```typescript

```

## 3. 命名规范

### 3.1 文件命名

```
✅ 推荐：
- UserProfile.vue      # PascalCase，多单词
- EzButton.vue         # 二次封装组件，Ez 前缀
- useAuth.ts           # 组合式函数，use 前缀
- userStore.ts         # Store，小驼峰

❌ 避免：
- profile.vue          # 单单词
- button.vue           # 单单词
- helper.ts            # 太通用
```

### 3.2 组件命名

```vue
<!-- ✅ 推荐：PascalCase -->
<script setup lang="ts">
import UserProfile from '@/components/UserProfile.vue'
import EzButton from '@/components/EzButton.vue'
</script>

<template>
  <UserProfile />
  <EzButton>点击</EzButton>
</template>
```

### 3.3 变量命名

```typescript
// ✅ 推荐
const userName = 'admin'
const getUserInfo = () => {}
const UserRoles = ['admin', 'user']

// ❌ 避免
const user_name = 'admin'
const getuserinfo = () => {}
```
