# Ez-Admin-NaiveUI 后台管理系统教学大纲

## 项目简介

这是一个从零到一的教学项目，旨在帮助开发者掌握基于 **Vue 3 + TypeScript + Vite + Tailwind CSS + NaiveUI** 的后台管理系统开发。

### 技术栈

- **框架**: Vue 3.5+ (Composition API + `<script setup>`)
- **语言**: TypeScript 5.0+
- **构建工具**: Vite 5.0+
- **组件库**: NaiveUI
- **样式方案**: Tailwind CSS
- **状态管理**: Pinia
- **路由**: Vue Router 4
- **HTTP 客户端**: Axios
- **代码规范**: ESLint + Prettier

### 学习目标

通过本教程，你将学会：

1. ✅ 现代化前端工程化配置
2. ✅ TypeScript 在 Vue 3 中的最佳实践
3. ✅ Tailwind CSS 原子化 CSS 开发模式
4. ✅ NaiveUI 组件库的深度使用
5. ✅ 组件封装与复用技巧
6. ✅ 权限系统设计方案
7. ✅ 后台管理系统通用功能实现

## 常见问题

### Q: 为什么选择 NaiveUI 而不是 Element Plus？
A: NaiveUI 是 TypeScript 原生组件库，类型提示更完善，且设计更现代化。

### Q: Tailwind CSS 和 scoped CSS 如何选择？
A: 本项目使用 Tailwind CSS 处理所有样式，包括布局、间距、响应式等。scoped CSS 仅用于特殊动画或复杂选择器。

### Q: 如何处理组件的样式覆盖？
A: 优先使用 Tailwind 的类名组合，NaiveUI 组件通过 `:deep()` 选择器覆盖样式。
