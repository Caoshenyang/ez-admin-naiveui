## 1. 响应式断点

### 1.1 Tailwind 默认断点

```javascript
// tailwind.config.js
export default {
  theme: {
    screens: {
      'sm': '640px',   // 平板
      'md': '768px',   // 小型笔记本
      'lg': '1024px',  // 桌面
      'xl': '1280px',  // 大屏幕
      '2xl': '1536px', // 超大屏幕
    },
  },
}
```


## 6. 媒体查询

### 6.1 CSS 媒体查询

```vue
<style scoped>
.container {
  padding: 1rem;
}

@media (min-width: 768px) {
  .container {
    padding: 2rem;
  }
}
</style>
```

### 6.2 组合式 API 媒体查询

**src/composables/useMediaQuery.ts**:

```typescript
import { ref, onMounted, onUnmounted } from 'vue'

export function useMediaQuery(query: string) {
  const matches = ref(false)

  let mediaQuery: MediaQueryList

  const update = () => {
    matches.value = mediaQuery.matches
  }

  onMounted(() => {
    mediaQuery = window.matchMedia(query)
    update()
    mediaQuery.addEventListener('change', update)
  })

  onUnmounted(() => {
    mediaQuery?.removeEventListener('change', update)
  })

  return matches
}
```

使用：
```vue
<script setup lang="ts">
import { useMediaQuery } from '@/composables/useMediaQuery'

const isMobile = useMediaQuery('(max-width: 768px)')
</script>

<template>
  <div v-if="isMobile">移动端内容</div>
  <div v-else>桌面端内容</div>
</template>
```

## 7. 最佳实践

### 7.1 移动优先

```vue
<!-- ✅ 移动优先 -->
<div class="w-full md:w-1/2 lg:w-1/3">
  先设计移动，再适配桌面
</div>

<!-- ❌ 桌面优先 -->
<div class="w-1/3 md:w-full">
  先设计桌面，再适配移动
</div>
```

### 7.2 断点一致

```javascript
// tailwind.config.js
export default {
  theme: {
    screens: {
      // ✅ 使用标准断点
      'sm': '640px',
      'md': '768px',
      'lg': '1024px',

      // ❌ 避免过多自定义断点
      'custom-1': '555px',
      'custom-2': '777px',
    },
  },
}
```
